# XIV Launch Manager

Windows 用的 FINAL FANTASY XIV 非官方啟動器，同時管理國際服與繁中服的帳號，並支援 Dalamud 與 ACT。

主要功能：

- 國際服、繁中服帳號放在同一個清單，選好帳號按「登入」就進遊戲，可以同時開多個帳號。
- 密碼與 OTP 金鑰存在 Windows 認證管理員，OTP 可以自動產生。
- Dalamud：兩服各自下載，每個帳號用自己的設定檔，可以沿用 XIVLauncher、TC 啟動器原本的資料。
- ACT：登入後自動開啟，「ACT 連動」自動選到剛開的遊戲，也能兩服雙開。
- 角色設定：備份、還原，把熱鍵欄、巨集、按鍵等設定轉移到另一個角色（可跨服）。
- 遊戲更新在本程式內完成，本程式也會自動更新。

## 安裝

到 [Releases 頁面](https://github.com/Yshawn6720/xiv-launch-manager/releases/latest) 下載 `XIV.Launch.Manager_<版本>_x64-portable.exe`，放在任何你有寫入權限的資料夾就能直接執行。不要放在 Program Files，否則無法自動更新。

想要開始選單捷徑，可以改用 `XIV.Launch.Manager_<版本>_x64-setup.exe` 安裝版。

需要 Windows 10／11 與 WebView2（Windows 10／11 通常已內建；安裝版缺少時會自動安裝）。請只從官方 Releases 下載本程式。

## 新增帳號

1. 到「設定」分頁的「遊戲路徑」，按「自動偵測」或自己填入遊戲根目錄，再按「儲存」。
2. 回到「登入」分頁，按側欄的「新增帳號」。
3. 選區服，填帳號、密碼。勾選「記住密碼」就不用每次輸入。
4. 選 OTP 方式：
   - 「不使用」：帳號沒有綁 OTP。
   - 「每次輸入」：登入時手動輸入。
   - 「自動產生」：貼上 OTP 的 base32 金鑰，登入時自動產生。可以用「目前 OTP」和手機的驗證器 App 比對。
5. 按「登入」，或按「僅儲存」只存不登入。

密碼和 OTP 金鑰存在 Windows 認證管理員，不會寫進設定檔。

## 登入

在側欄點選帳號，按「登入」。

**國際服**：OTP 選「每次輸入」時，填在「OTP 碼」欄；留空的話，登入途中會跳出視窗請你輸入。

**繁中服**：

1. 按「登入」後，會跳出「繁中服登入確認」視窗。
2. 確認帳號，再按視窗裡的「登入」。OTP 選「每次輸入」時，先在這個視窗的「OTP 碼」欄輸入。
3. 視窗顯示「登入中…」，完成後自動關閉。按「取消」就是取消這次登入。
4. 遊戲啟動後，登入頁頁首（帳號名稱旁）會顯示「遊戲時間 剩餘約 N 天 HH:MM 登入」（不到一天時以小時顯示，沒有期限時顯示「無限制」），是那次登入時繁中服回報的值，選中該帳號時才顯示，重開本程式後要再登入一次才會顯示；伺服器沒給或格式不認得時顯示「無法取得」，不影響登入。國際服登入流程沒有這項資料，請到 Mog Station 查看。

**進階**：表單下方的「進階」可以選這個帳號用哪個「Dalamud 設定檔」、國際服的遊戲語言，以及「ACT 跟這個帳號」。其他選項一般不用動。

帳號名稱右側的三點選單可以重新命名、刪除帳號，以及檢查遊戲更新或遊戲檔。

側欄消息標題（「國際服消息」／「繁中服消息」）右邊的「水晶商城」按鈕會用預設瀏覽器開啟目前帳號那一服的官方商城：國際服是 Mog Station，繁中服是官方水晶商城。本程式不會替你登入商城。

遊戲啟動後主視窗要不要收起，在「設定」的「遊戲啟動後」選「不動作」「最小化」或「縮到系統匣」。新安裝時介面是深色，可在「設定」的「主題」改成淺色或跟隨系統；2026-10-30 前存過設定的使用者，設定檔裡已是「跟隨系統」，維持不變，要深色請在「主題」選「深色」。

## Dalamud

位置：「擴充功能」 › 「Dalamud」，上方分頁切換「國際服」「繁中服」。

國際服的 Dalamud 來自 goatcorp，繁中服來自 GitHub 上的 yanmucorp，兩服分開管理。

1. 在「版本」按「下載」。不先下載也沒關係，登入時會自動下載。
2. 準備設定檔（決定用哪一套插件與設定）：
   - 用過 XIVLauncher 或 TC 啟動器的話，原本的 Dalamud 資料會自動列出來，直接選用即可，插件與設定都沿用。
   - 沒有的話，按「新增空白設定檔」。
3. 到「登入」分頁，在帳號的「進階」選 Dalamud 的「設定檔」。

同一份設定檔可以同時給兩個遊戲用，但兩邊改的設定（含插件設定）會互相覆蓋，第一次共用時會先跳出確認。要同時開兩個同服帳號，建議按設定檔的「複製」做出第二份，各用各的。

## ACT

位置：「擴充功能」 › 「ACT」。

**基本設定**：在「國際服」「繁中服」分頁用下拉選單選 ACT（兩服可以共用一個），勾選登入後自動開啟 ACT。

**ACT 連動**：登入後讓 ACT 的 FFXIV 插件自動選到剛開的遊戲。

1. 每個 ACT 先開過一次。
2. 關閉所有 ACT。
3. 按「啟用 ACT 連動」。下次開 ACT 時生效。

**雙開**：想讓國際服、繁中服各用一個 ACT：

1. 在原本的 ACT 裡把 FFXIV 插件的 Region 選好。
2. 關閉所有 ACT。
3. 按「建立另一服的 ACT（雙開）」。新的 ACT 會自動設定好，兩個都會啟用連動。

**同一服開多個帳號**：每一服的 ACT 只跟一個遊戲。把小號「進階」裡的「ACT 跟這個帳號」取消勾選，ACT 就不會被小號搶走。

## 角色

位置：「角色」分頁。這裡列出這台電腦登入過的角色（`文件\My Games` 下的 `FFXIV_CHR…` 資料夾）。資料夾裡沒有角色名稱，展開角色後自己取個名字比較好認。

- **備份**：展開角色按「備份」。不含聊天紀錄（`log` 資料夾）。
- **還原**：在備份清單按「還原」。
- **轉移**：上方選來源、目標角色，勾要轉的設定（熱鍵欄、角色巨集、按鍵綁定、聊天過濾、HUD 與視窗配置、角色設定、操作設定），按「轉移」。可以跨服；兩服格式不同的設定會標「不轉」並寫原因。
- 還原、轉移前會自動備份目標角色（每個角色留最新 10 份），弄錯了可以從備份還原。
- 還原、轉移前請先關閉該區服的遊戲與官方啟動器。
- 本程式開的遊戲關掉後，角色會標上「最後由 <帳號> 使用」。

## 遊戲更新

- 按「登入」時發現需要更新，會自動下載並套用。完成後再按一次「登入」。
- 繁中服會在背景自動檢查，需要更新時「登入」上方會出現「更新」按鈕。
- 國際服裝在 Program Files 等受保護的位置時，更新前會跳出 UAC，請按「是」。
- 請以一般身分執行本程式：以系統管理員身分執行、而國際服裝在一般權限就能修改的位置時，不會更新國際服；關閉 UAC 的系統管理員帳號也不能在本程式更新國際服。
- 繁中服的更新不會另外跳 UAC：以系統管理員身分執行本程式時，會直接以系統管理員權限寫入繁中服的遊戲資料夾，所以也建議以一般身分執行。
- 國際服可以從帳號的三點選單「檢查遊戲檔完整性」。只檢查、不修復，有問題請用官方啟動器修復。
- 官方啟動器本身（boot）需要更新時，請用官方啟動器更新一次。

## 國際服字體與漢化包

> **風險**：這是對遊戲用戶端的非官方修改，違反 Square Enix 的使用者協議，可能導致帳號被處分。是否使用、以及因此造成的帳號處分或其他損失，由你自行承擔。本功能預設關閉，第一次開啟時會再請你確認一次。

把字體包、GP 漢化器（FFXIVChnTextPatch-GP）產生的漢化包放在遊戲資料夾以外的「外部包資料夾」，登入國際服時由本程式套用。遊戲資料夾本身維持官方原檔，遊戲更新與「檢查遊戲檔完整性」都照常。只用於國際服，繁中服不套用。

**使用方式**：

1. 新增一個資料夾，和遊戲放在同一個磁碟，但不要放在遊戲資料夾裡。放入要替換的 sqpack 檔，檔名和遊戲 `game\sqpack\ffxiv\` 裡的官方檔相同，例如字體的 `000000.win32.dat0`、`000000.win32.index`、`000000.win32.index2`，漢化的 `0a0000.win32.dat0`、`0a0000.win32.index`、`0a0000.win32.index2`。每組至少要有 `.dat0` 和 `.index`。
2. 到「設定」的「國際服外部包」按「選擇資料夾」選這個資料夾（也可以直接貼上路徑），按「儲存」，再打開開關，閱讀風險說明後確認。區塊下方的「說明」整理了要放什麼、怎麼運作與限制。
3. 照常登入國際服。

本程式會在遊戲資料夾旁邊建一個 `xiv-launch-manager-shadow` 資料夾（影子資料夾），以連結的方式組合官方檔與外部包，再從這裡啟動遊戲；不另外佔用遊戲大小的空間。登入時檢查影子資料夾，第一次使用或檔案有變時才重建；已有影子的遊戲在執行時沿用，不重建。需要重建且遊戲裝在 Program Files 等受保護的位置時，會跳出 UAC，請按「是」；按「否」這次就以原版遊戲啟動。之後沒有變動就不會再問。關閉功能後可以用檔案總管刪除影子資料夾；裡面有連到遊戲資料夾的連結，不要用會跟著連結刪除內容的工具或指令。

請以一般身分執行本程式：以系統管理員身分執行、而遊戲裝在一般權限就能修改的位置時，不會建立影子資料夾；關閉 UAC 的系統管理員帳號也不能使用外部包。

不要用 GP 漢化器、TexTools 等任何工具修改影子資料夾裡的檔案：除了外部包的檔案，其他檔案就是遊戲資料夾的官方原檔，改了等於直接改遊戲。也不要把檔案放進影子資料夾（例如讓 ReShade 把截圖存在遊戲執行檔旁）：重建時影子資料夾會整個刪掉，所以本程式發現影子裡有建好之後才放進去的檔案時不會重建，這次以原版遊戲啟動並列出這些檔案，請移到別處。

**遊戲更新後**：外部包是對某一版官方檔做的。每次登入前，本程式會比對外部包和目前遊戲檔的版本；不符時照原版遊戲啟動，並提示「外部包已過期」。這時重新產生外部包：

1. 等遊戲更新完成。
2. 把遊戲資料夾 `game\sqpack\ffxiv\` 裡新版官方的 `000000.*`、`0a0000.*` 複製到另一個工作資料夾。不要直接改遊戲資料夾裡的檔案。
3. 用 GP 漢化器對這份副本做漢化或換字體。
4. 把產出的檔案放進外部包資料夾，取代舊檔。

## 本程式更新

有新版時，標題列會出現「更新至 x.y.z」，按下後自動下載、安裝並重新開啟。

從 0.2.1 起，遊戲執行中也能更新。正在登入或下載時不能更新，完成後再按即可。

兩種版本都會自動更新，免安裝版更新時會替換自己。

## 常見問題

### 繁中服登入回「連線錯誤，請稍後再試。」

這是繁中服伺服器回的訊息。請稍後再試，或先用 TC 啟動器登入。

### 顯示「遊戲啟動後立即結束（可能超過客戶端實例上限）」

同時開的遊戲可能太多，先關掉一個再登入。

### Dalamud 被暫停使用，或不支援目前遊戲版本

遊戲改版後常見。等 Dalamud 更新，或在「進階」的「本次載入方式」選「不載入 Dalamud」先進遊戲。

國際服另有「強制載入（忽略遊戲版本）」：略過版本檢查硬載入 Dalamud，可能讓遊戲崩潰或插件出錯。登入前會先跳警告，只用於這一次登入。Dalamud 被官方暫停時無效。

### 自動產生的 OTP 被拒絕

OTP 依電腦時間計算，請在 Windows 設定開啟自動設定時間。

### 資料放在哪裡？

在「設定」的「資料位置」按「開啟資料夾」。Dalamud 的 log 在設定檔「更多」裡的「開啟 log」。
