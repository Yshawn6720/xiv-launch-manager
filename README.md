# XIV Launch Manager

Windows 用的 FINAL FANTASY XIV 非官方啟動器，同時管理國際服與繁中服的帳號，並支援 Dalamud 與 ACT。

主要功能：

- 國際服、繁中服帳號放在同一個清單，選好帳號按「登入」就進遊戲，可以同時開多個帳號。
- 密碼與 OTP 金鑰存在 Windows 認證管理員，OTP 可以自動產生。
- Dalamud：兩服各自下載，每個帳號用自己的設定檔，可以沿用 XIVLauncher、TC 啟動器原本的資料。
- ACT：登入後自動開啟，「ACT 連動」自動選到剛開的遊戲，也能兩服雙開。
- 遊戲更新在本程式內完成，本程式也會自動更新。

## 安裝

到 [Releases 頁面](https://github.com/Yshawn6720/xiv-launch-manager/releases/latest) 下載 `XIV.Launch.Manager_<版本>_x64-portable.exe`，放在任何你有寫入權限的資料夾就能直接執行。不要放在 Program Files，否則無法自動更新。

想要開始選單捷徑，可以改用 `XIV.Launch.Manager_<版本>_x64-setup.exe` 安裝版。

需要 Windows 10／11 與 WebView2（Windows 10／11 通常已內建；安裝版缺少時會自動安裝）。請只從官方 Releases 下載本程式。

## 新增帳號

1. 到「設定」分頁的「遊戲路徑」，按「自動偵測」或自己填入遊戲根目錄，再按「儲存」。
2. 回到「登入」分頁，按側欄的「新增帳號」。
3. 選區服，填帳號、密碼。勾選「記住密碼」就不用每次輸入。
4. 選 OTP 方式：
   - 「不使用」：帳號沒有綁 OTP。
   - 「每次輸入」：登入時手動輸入。
   - 「自動產生」：貼上 OTP 的 base32 金鑰，登入時自動產生。可以用「目前 OTP」和手機的驗證器 App 比對。
5. 按「登入」，或按「僅儲存」只存不登入。

密碼和 OTP 金鑰存在 Windows 認證管理員，不會寫進設定檔。

## 登入

在側欄點選帳號，按「登入」。

**國際服**：OTP 選「每次輸入」時，填在「OTP 碼」欄；留空的話，登入途中會跳出視窗請你輸入。

**繁中服**：

1. 按「登入」後，會跳出「繁中服登入確認」視窗。
2. 確認帳號，再按視窗裡的「登入」。OTP 選「每次輸入」時，先在這個視窗的「OTP 碼」欄輸入。
3. 視窗顯示「登入中…」，完成後自動關閉。按「取消」就是取消這次登入。

**進階**：表單下方的「進階」可以選這個帳號用哪個「Dalamud 設定檔」、國際服的遊戲語言，以及「ACT 跟這個帳號」。其他選項一般不用動。

帳號名稱右側的三點選單可以重新命名、刪除帳號，以及檢查遊戲更新或遊戲檔。

遊戲啟動後主視窗要不要收起，在「設定」的「遊戲啟動後」選「不動作」「最小化」或「縮到系統匣」。

## Dalamud

位置：「擴充功能」 › 「Dalamud」，上方分頁切換「國際服」「繁中服」。

國際服的 Dalamud 來自 goatcorp，繁中服來自 GitHub 上的 yanmucorp，兩服分開管理。

1. 在「版本」按「下載」。不先下載也沒關係，登入時會自動下載。
2. 準備設定檔（決定用哪一套插件與設定）：
   - 用過 XIVLauncher 或 TC 啟動器的話，原本的 Dalamud 資料會自動列出來，直接選用即可，插件與設定都沿用。
   - 沒有的話，按「新增空白設定檔」。
3. 到「登入」分頁，在帳號的「進階」選 Dalamud 的「設定檔」。

同一份設定檔可以同時給兩個遊戲用，但兩邊改的設定（含插件設定）會互相覆蓋，第一次共用時會先跳出確認。要同時開兩個同服帳號，建議按設定檔的「複製」做出第二份，各用各的。

## ACT

位置：「擴充功能」 › 「ACT」。

**基本設定**：在「國際服」「繁中服」分頁用下拉選單選 ACT（兩服可以共用一個），勾選登入後自動開啟 ACT。

**ACT 連動**：登入後讓 ACT 的 FFXIV 插件自動選到剛開的遊戲。

1. 每個 ACT 先開過一次。
2. 關閉所有 ACT。
3. 按「啟用 ACT 連動」。下次開 ACT 時生效。

**雙開**：想讓國際服、繁中服各用一個 ACT：

1. 在原本的 ACT 裡把 FFXIV 插件的 Region 選好。
2. 關閉所有 ACT。
3. 按「建立另一服的 ACT（雙開）」。新的 ACT 會自動設定好，兩個都會啟用連動。

**同一服開多個帳號**：每一服的 ACT 只跟一個遊戲。把小號「進階」裡的「ACT 跟這個帳號」取消勾選，ACT 就不會被小號搶走。

## 遊戲更新

- 按「登入」時發現需要更新，會自動下載並套用。完成後再按一次「登入」。
- 繁中服會在背景自動檢查，需要更新時「登入」上方會出現「更新」按鈕。
- 國際服裝在 Program Files 等受保護的位置時，更新前會跳出 UAC，請按「是」。
- 國際服可以從帳號的三點選單「檢查遊戲檔完整性」。只檢查、不修復，有問題請用官方啟動器修復。
- 官方啟動器本身（boot）需要更新時，請用官方啟動器更新一次。

## 本程式更新

有新版時，標題列會出現「更新至 x.y.z」，按下後自動下載、安裝並重新開啟。

從 0.2.1 起，遊戲執行中也能更新。正在登入或下載時不能更新，完成後再按即可。

兩種版本都會自動更新，免安裝版更新時會替換自己。

## 常見問題

### 繁中服登入回「連線錯誤，請稍後再試。」

這是繁中服伺服器回的訊息。請稍後再試，或先用 TC 啟動器登入。

### 顯示「遊戲啟動後立即結束（可能超過客戶端實例上限）」

同時開的遊戲可能太多，先關掉一個再登入。

### Dalamud 被暫停使用，或不支援目前遊戲版本

遊戲改版後常見。等 Dalamud 更新，或在「進階」的「本次載入方式」選「不載入 Dalamud」先進遊戲。

國際服另有「強制載入（忽略遊戲版本）」：略過版本檢查硬載入 Dalamud，可能讓遊戲崩潰或插件出錯。登入前會先跳警告，只用於這一次登入。Dalamud 被官方暫停時無效。

### 自動產生的 OTP 被拒絕

OTP 依電腦時間計算，請在 Windows 設定開啟自動設定時間。

### 資料放在哪裡？

在「設定」的「資料位置」按「開啟資料夾」。Dalamud 的 log 在設定檔「更多」裡的「開啟 log」。
